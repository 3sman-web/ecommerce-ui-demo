# CodeWave – E-Commerce UI Demo

## 📌 English

**CodeWave** is a modern, responsive **E-Commerce User Interface demo** built using **pure HTML and CSS**.  
This project is designed as a **frontend showcase** for portfolio purposes and client demonstrations.

### ✨ Features
- Fully responsive design (Desktop & Mobile)
- Clean and modern UI/UX
- Arabic (RTL) layout support
- Hero section, categories, products, and footer
- Uses Google Fonts & Font Awesome icons
- No frameworks or libraries required

### 🛠 Technologies Used
- HTML5
- CSS3 (Flexbox & Grid)
- Google Fonts
- Font Awesome

### 🚀 Live Demo
👉 **GitHub Pages:**  
https://3sman-web.github.io/ecommerce-ui-demo/

### 📂 Project Purpose
This project is created for:
- UI/UX demonstration
- Frontend portfolio showcase
- Upwork / freelance portfolio projects
- UI inspiration for e-commerce websites

### ⚠️ Note
This is a **UI only demo** (no backend, no database, no cart functionality).
